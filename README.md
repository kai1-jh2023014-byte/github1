# github1

「時卓 -JiTaku-」の試作Webアプリです。

## この試作で対応した内容

- 時間割の**表形式 / カレンダー形式**切り替え
- 1マス内に**クラス・科目・課題・持ち物**を表示
- 教員向けの**手動登録**
- 教員向けの**クイック入力（テキストの簡易AI仕分け）**
  - 例: 「明日の3組の英語は、ワーク25ページと辞書を持ってきてください」
- 生徒向けの**忘れ物防止リマインダー試作**
  - 今日のチェックリスト作成
  - 前夜通知（試作ボタン）
  - 翌朝の未チェック再通知（試作ボタン）
- **部活連動持ち物**（部活曜日 + 部活持ち物）

## 使い方

1. `/home/runner/work/github1/github1/index.html` をブラウザで開く
2. 「③ 持ち物・課題クイック入力（教員）」で時間割情報を登録
3. 「① アジャイル時間割・カレンダー」で表示確認
4. 「② 忘れ物ゼロ！お節介リマインダー（生徒）」でチェックリストと通知を試す

## 注意

- 本実装は**まずは仮で作る試作版**です。
- リアルタイム同期、音声入力、Classroom API連携、バックエンド通知スケジューラは未実装で、画面内の試作挙動で代替しています。
